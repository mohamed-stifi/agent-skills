# Audio: voice, music, sound design, captions

Everything is generated by `source/audio/engine.py` from `source/audio/films.py`. Read the docstring at the top of films.py.

## Voice
- Default: **Kokoro-82M**, voice **`af_heart`** (best quality), speed 1.0, `lang: 'en-us'`, `lang3: 'eng'`.
- Another Kokoro voice or language (the user asked): set `voice`, `lang`, `lang3` on the film. List voices with
  `cd <WS>/source/audio && uv run python engine.py --voices`. Kokoro languages: en-us, en-gb, fr-fr, es, it, pt-br, hi,
  ja, zh (prefix of voice names: a/b English US/UK, f French, e Spanish, i Italian, p Portuguese, h Hindi, j Japanese,
  z Chinese).
- **Another model** the user names (for a language or voice Kokoro lacks): write `source/audio/tts_custom.py` with
  `def say(text, voice, speed, lang) -> (numpy float array, sample_rate)` that calls it; the engine uses it automatically.
  Install its package with `uv add --project <WS>/source/audio <package>`.
- Fit: the engine re-voices a line faster (≤ 1.22×) if it would run into the next line; `allowOverrun: True` lets a line
  cross a scene cut on purpose (the promise line often does).

## Pronunciation (always check, max 2 fix rounds)
`check.sh` transcribes the finished films with Whisper. Any word heard wrong (product name, a person's name, a unit,
a term) gets a `say` respelling and the film is re-voiced. Respellings that worked: `Re-runs` (not "Rerun's"),
`cut-over`, `deer-hams` (dirhams), `Rashid` (Rachid), `data ops` (DataOps), times spelled out (`four fifty-two`).
If a first word is swallowed, rephrase so the line opens on a strong syllable.

## Music map (synthesized; no licences)
`[(start, end, kind)]` aligned to the story:

| kind | use for | character |
|---|---|---|
| `busy` | an everyday-work hook | pluck ostinato that tightens |
| `dark` | night, failure, risk, the problem | drone → pulse → hats, building |
| `drive` | the solution chapters | Am–F–C–G at 120 BPM, kick, arp, pad |
| `lift` | the promise | F–G–C–Cadd9, brighter, bigger |
| `resolve` | CTA / end card | sustained Cadd9 + motif, fades to silence at the end |

The music ducks 7 dB under the voice automatically. Master: −14 LUFS, true peak −1.5 dBTP.

## Cue sheet (sound design synced to the picture)
Build it from the subagents' reports (frame numbers of snaps, stamps, counts, whips, exits): `at(S['S04'], 154)`.
Conventions: every cut gets `into` (ends on the cut) + `arrive` at the next scene start; every decisive snap gets
`antic` before it and `impact` (size 0.5–1.2) on landing; approvals/gates get `stamp`; counters `count`; failures
`error`; passes climbing `pass` with rising `step`; the brand reveal `reveal` (+ `riser` peaking on it); headline
entries `swoosh`; the CTA mark `impact` + `shimmer`. Defaults levels are in `LEVEL` (override with `db`).
Less is more: one sound per visual event, nothing during held reading moments.

## Captions
- Soft track inside `<id>-final.mp4` (viewers can switch it on), `.srt` + `.vtt` + transcript in `output-extras/`.
- Burned-in `<id>-captioned.mp4` (for muted autoplay feeds): `captions.sh`, styled in `src/Captioned.tsx`.
- Caption text = `text` of each line, split into ≤ 7-word chunks at punctuation.
